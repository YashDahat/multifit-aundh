# MultiFit Aundh

Auto-generated website for MultiFit Aundh — Gym, Multifit Aundh , D.P. Road Medipoint Hospital Road, opp. to Indian Bank, Aundh, Pune, Maharashtra 411067.

## Tech Stack

- **backend**: Gym Management SaaS API (e.g., Glofox, WellnessLiving) to handle all membership, booking, and payment logic.
- **hosting**: Vercel or Netlify for the frontend, ensuring high performance and scalability.
- **database**: Managed by the selected Gym Management SaaS.
- **frontend**: Next.js (React) for a fast, SEO-friendly, and interactive user experience.

## Features

- Online membership purchase and management
- Integrated class schedule with online booking
- Prominent 'Get a 3-Day Free Trial' lead capture form
- Mobile-first responsive design
- Trainer profile pages with specializations
- Integration with social media feeds (Instagram/Facebook)
- Testimonials section featuring their high Google rating

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
